# 怎么用

<sub>[English](usage.md)</sub>

```bash
gerdr             # 起服务，打印一个带令牌的链接，用浏览器打开
gerdr --open      # 起服务并打开浏览器
gerdr url         # 再拿一次登录链接
gerdr acp claude  # 把内置适配器当 stdio ACP agent 跑（给 Zed 等 ACP 客户端用）
```

桌面 App 和命令行可以同时用：App 发现已经有一个 Gerdr 在跑，就直接连它，看到的是同一份会话。mac 上打开 设置 → 通用 →「后台常驻」，⌘Q 退出 App 会话也照跑（[细节](../dev/SERVICE.md)）。

新建会话：选 agent、选目录、开始。下面会列出这个目录下以前的会话，点一下接着聊。

输入框：回车发送，Shift+回车换行（设置里可以改成 ⌘+回车）；`/` 出斜杠命令；Esc 打断；
粘贴 / 拖进来的图片会一起发。agent 在跑的时候发送 = 插话（Ctrl+回车 = 立即插话）。

鼠标移到自己说过的话上点 ↺，再点一次（或回车）确认，就回到这句之前：这句和后面的对话丢掉，原话（文字和图）放回输入框，原样重发直接点发送，想改就改。只退对话，文件不会恢复。

## 快捷键

和 herdr / tmux 一样：先按前缀 `ctrl+b`，松开，再按：

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `v` | 左右分屏 | `-` | 上下分屏 |
| `h j k l` / 方向键 | 切 pane | `shift+h/j/k/l` | 和邻居交换 |
| `x` | 关 pane | `z` | 放大 / 还原 |
| `c` | 新 tab | `n` / `p` | 下一个 / 上一个 tab |
| `1`…`9` | 跳到第几个 tab | `;` | 上次的 tab |
| `shift+x` | 关 tab | `shift+t` | 重命名 tab |
| `shift+n` | 新工作空间 | `w` | 切工作空间 |
| `g` | 会话列表 | `o` | 跳到在等你的会话 |
| `u` / `d` | 上一个 / 下一个要你处理的会话 | `:` | 命令面板（也可以 ⌘K） |
| `t` | 开终端（跟着当前目录） | `b` | 侧栏 |
| `i` | 右边开浏览器 | `?` | 全部快捷键 |

中文输入法开着也能用（按物理键位认键）。全部可以在「设置 → 快捷键」里改。
mac App 里另有 ⌘T 新 tab、⌘1…9 跳到侧栏「进行中」的第 N 个 agent（按住 ⌘ 会显示编号；切 tab 用 prefix+1…9）、⌘E 回到上一个 tab（跨工作空间）这些菜单快捷键；⌘D / ⌘⇧D 把焦点那个复制一份放右边 / 下面（会话就是同 agent、同目录、同模式的新会话，直接开起来；终端就是同目录终端），要空面板用 prefix+v / prefix+-。

## 浏览器面板

对话旁边可以开一个浏览器：pane 的「⋯」菜单 →「右边开浏览器」，或者 `prefix+i`，在顶上输入网址。agent 用
`gerdr browser open` 打开的网页也会出现在它旁边，你能看着它操作，也能自己点、自己打字（中文输入法、粘贴都行），
比如替它登录、过验证码。

每个项目有一个自己的浏览器（profile 放在 `~/.gerdr/projects/<项目>/browser`）：在这个项目里登录过的网站会一直保持登录，
别的项目看不到。它是 Gerdr 在后台跑的 Chrome（用这台电脑装的 Chrome / Edge / Brave / Chromium），画面一块一块传过来，
所以手机上、远程访问时也看得到、点得了。要让 agent 用你平时那个已经登录好的 Chrome，见下面的浏览器插件。

## 你自己的 Chrome（浏览器插件）

项目浏览器一开始什么都没登录。agent 要用你自己的账号（公司后台、平时常用的网站），你又不想在项目浏览器里再登录一次，
就在平时用的 Chrome 里装 **Gerdr 浏览器插件**：设置 → 浏览器 →「从 Chrome 应用商店安装」
（[商店页面](https://chromewebstore.google.com/detail/hkooiloghnflaffpkfapfodomgkdpnff)）。Chrome 开着、Gerdr 在运行，
它就会自动连上；设置 → 浏览器 里能看到连上了哪些 Chrome、各自允许了哪些网站。

你让 agent 用它时它才用（`gerdr browser open --chrome`）。它能做的事是受限的：

- agent 第一次要用某个网站时，插件弹窗问你，只允许这一个网站；点 Chrome 工具栏上的插件图标能看到、移除允许的网站；
- 只在它自己打开的标签页里操作，这些标签页在 Chrome 里归在「Gerdr」组、页面带蓝色边框；页面离开允许的网站就停止控制；
- 不读取、不修改 cookie 和网站存储，只和同一台电脑上的 Gerdr 通信。

有几个 Chrome 用户？点插件图标给每个起个名字（「工作」「个人」），告诉 agent 用哪个就行。隐私政策：https://gerdr.dev/privacy 。

## 内存

- Codex：所有会话共用一个 `codex app-server` 进程（几十 MB）。
- Claude Code：一个会话一个 `claude` 进程（几百 MB，CLI 的结构）。闲置 15 分钟的会话会被收掉进程，
  下次说话时自动 `--resume`，对话不丢。
- Gerdr 本身：一个 Go 进程，没有 node。
